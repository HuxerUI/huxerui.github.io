---
title: ExternalTexture
description: Present live platform-produced frames inside ordinary Image layout.
---

Use an external texture for video, camera previews, or GPU output when HuxerUI should own layout, input, and composition.

## Share one producer identity

```cpp compile="external-texture-consumer"
#include <huxerui/huxerui.h>

#include <memory>

using namespace huxerui;

View Preview(const std::shared_ptr<ExternalTexture>& texture) {
  if (!texture) {
    return Text("No preview");
  }
  return Image(texture)
      .Fit(ImageFit::Cover)
      .With(Frame{.height = 180.0F});
}
```

The integration constructs a supported platform texture; consumers share the pointer. Publishing frames does not need per-frame State updates.

## Lifetime and alternatives

`IntrinsicSize()` describes immutable logical geometry; frame pixels may have a different resolution. `Revision()` detects publications, and `IsActive()` is a hint that a Runtime is displaying the texture. The producer still owns start, pause, and finish policy.

Use a static [Image](/docs/components/image/) for encoded resources, or [PlatformView](/docs/components/platform-view/) when the platform object must retain its own interaction and accessibility.

See [producer integration](/docs/guides/external-texture/) and the [API reference](/docs/reference/external-texture/).
