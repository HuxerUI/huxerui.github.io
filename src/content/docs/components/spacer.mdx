`Spacer` is an empty layout component used to push siblings apart.

```cpp fragment
Row {
  Text("Document"),
  Spacer(),
  Button("Save"),
}.With(CrossAlign(CrossAxisAlignment::Center))
```

In a `Row`, it consumes available horizontal space; in a `Column`, it consumes available vertical space.
Use `Grow(factor)` on ordinary content when the flexible region itself should render or participate in semantics.

`Spacer` has no content, events, or accessibility semantics.

## API

- Constructor: `Spacer()`.
- Common modifiers: `Frame` for a fixed minimum gap and `Grow` for explicit proportional behavior.

See [Row](../row/) and [Column](../column/) for flexible-axis behavior and alignment rules.
