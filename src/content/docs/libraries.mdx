Add individual libraries as your application needs them. Each project documents its own public headers, supported platforms, and build prerequisites.

**Release** links to published GitHub releases. **Source** indicates a project available from a source checkout. Check the selected library revision's requirements before pairing it with your HuxerUI SDK.

## Add a library

In a CMake application, call `huxerui_use_library` after creating the app target. This example adds the published SQLite library to an app named `notes`:

```cmake
huxerui_use_library(notes
        TARGET HuxerUI::SQLite
        URL "https://github.com/HuxerUI/Lib-SQLite.git"
        TAG "v0.1.0"
)
```

Include `<huxerui/sqlite.h>` in the source files that use SQLite. This release supports desktop and mobile targets. For a library available from source, use `COMMIT` with a full commit SHA or `PATH` with a local checkout. See [CMake library integration](/docs/tooling/cmake/#use-a-huxerui-library) for dependency setup.
