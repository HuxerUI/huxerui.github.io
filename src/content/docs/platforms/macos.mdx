macOS applications use a native CMake/Xcode toolchain and AppKit host.

```bash
huxerui setup macos
huxerui run macos
```

The platform host owns `NSWindow`/`NSView` lifecycle, AppKit input and `NSTextInputClient`, accessibility, clipboard, files, HTTP, scheduling, and render-scene presentation. Logical HuxerUI geometry remains in DIPs and is converted at the host boundary.

`WindowChromeMode::System` retains native chrome. Custom chrome can compose application UI around platform window controls where supported; do not assume Windows caption geometry. Register NSView-backed platform views with `<huxerui/macos/platform_registry.h>` and publish external textures through `<huxerui/macos/external_texture.h>`.

Build and runtime validation require macOS and Xcode command-line tools.
The website's cross-platform contract checks do not substitute for AppKit accessibility, IME, NSView composition, signing, or device-scale validation.

## System capability boundaries

Local notifications use User Notifications for authorization, showing, scheduling, cancellation and primary activation. Default presentation is supported; template requests return Unavailable. Notification clicks enter OnActivation even when launching the process.

See [Local notifications](/docs/guides/local-notifications/) for shared usage and platform configuration, and [System API](/docs/reference/system/) for exact contracts.

## Application and window ownership

The application Runtime shares services, ordinary tasks and observable State across its UI attachments. Each UiWindow owns composition, focus, layers and presentation. This desktop backend implements OpenWindow; each created window has independent UI state and a fresh root Environment. See [Application and windows](/docs/guides/application-and-windows/).

System-theme preference is window-local and observed through UseSystemThemeBrightness. Custom font families retain application-supplied static data; test fallback and platform text scaling with localized content. Native runtime/device validation remains separate from website contract checks.
