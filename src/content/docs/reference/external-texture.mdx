## `ExternalTexture`

Default construction creates an empty handle. `IntrinsicSize()` returns the current logical source size; `HasValue()` reports a connected state; equality compares shared source identity. Platform-specific source types are the only producers.

The handle is accepted by `Image`, `ImageFill` is intentionally limited to static image/vector sources, and `PaintContext` has explicit external-texture drawing operations.
