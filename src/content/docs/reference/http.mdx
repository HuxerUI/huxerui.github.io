Declared by `<huxerui/http.h>`.

## Request and response values

- `HttpMethod`: `Get`, `Head`, `Post`, `Put`, `Patch`, `Delete`, `Options`.
- `HttpHeader`: name and value.
- `HttpRequest`: URL, method (default GET), headers, body, and optional timeout (default 30 seconds; `nullopt` disables it).
- `HttpResponse`: final URL, integer status code, headers, and body.

## Errors and result

`HttpErrorCode` is `Transport`, `Timeout`, or `Unsupported`. `HttpError` contains code and message. `HttpResult` constructs from response/error, reports `HasResponse`, and provides ref-qualified `Response()` plus lvalue `Error()` accessors; asking for the wrong alternative throws.

## `HttpClient`

Non-copyable root service. `Send(HttpRequest) const -> Task<HttpResult>`. Obtain it with `UseService<HttpClient>()`. Request cancellation follows the launched HuxerUI task execution.

## Complete request example

```cpp compile="http-request"
#include <huxerui/huxerui.h>

using namespace huxerui;

Task<void> LoadStatus(std::shared_ptr<HttpClient> http, State<std::string> output) {
  HttpResult result = co_await http->Send({
      .url = "https://example.com/status",
      .method = HttpMethod::Get,
  });
  output = result.HasResponse() ? std::to_string(result.Response().status_code) : result.Error().message;
}

[[huxerui::scope]]
View LoadStatusButton(State<std::string> output) {
  auto http = UseService<HttpClient>();
  auto tasks = UseTaskScope();
  return Button("Load status").OnClick([http, tasks, output] {
    tasks.Launch(LoadStatus(http, output));
  });
}
```

Resolve `HttpClient` and `TaskScope` during composition, then capture them in the event.
HTTP status codes are responses; transport, timeout, and unsupported-service failures use `HttpError`.
