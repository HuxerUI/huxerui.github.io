HuxerUI's initial website reference is a structured map of the supported public surface.
It deliberately avoids publishing a disconnected dump of generated C++ HTML.
Signatures and detailed contracts remain in the public headers and synchronized guides.

## Application and runtime

| Capability | Public header | Guide |
|---|---|---|
| Application declaration and options | `<huxerui/app.h>` | [Getting Started](/docs/getting-started/) |
| View, components, scopes, and state | `<huxerui/view.h>`, `<huxerui/state.h>` | [Core Concepts](/docs/core-concepts/) |
| Lifecycle and activation | `<huxerui/lifecycle.h>`, `<huxerui/app.h>` | [Application design](/docs/design/application/) |
| Tasks and UI-thread resumption | `<huxerui/task.h>` | [Task design](/docs/design/tasks/) |
