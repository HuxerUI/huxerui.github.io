Declared by `<huxerui/file.h>`.

## Results and metadata

- `FileType`: `File`, `Directory`, `Other`.
- `FileInfo`: type, byte size, optional modification time.
- `FileErrorCode`: `NotFound`, `PermissionDenied`, `NotDirectory`, `IsDirectory`, `TooLarge`, `InvalidEncoding`, `Unsupported`, `Io`.
- `FileError`: code and message.
- `FileResult<T>`: construct from value/error; `Succeeded`, ref-qualified `Value`, and `Error` accessors.

## `File`

Construct from UTF-8 path/string view or parent plus child. Path queries: `Path`, `Name`, `Stem`, `Extension`, `ParentPath`, `Parent`, `Child`, and `Resolve`. Status queries: `Exists`, `IsFile`, `IsDirectory`, synchronous/async `Stat`.

I/O methods have synchronous and `Async` forms: read bytes/string; write and append bytes/string; list children; create one/all directories; delete or recursively delete; copy; and move. Copy/move accept `overwrite = false`. Async methods return `Task`.

## `FileReference`

Capability for a selected or activated file. Metadata: `Name`, optional `Size`, optional `ContentType`, `CanWrite`. Async operations: `ReadBytesAsync`, `ReadStringAsync`, `ImportToAsync`, and `ReplaceWithAsync`.

## `FilePicker`

`FilePickerFilter` contains name, extensions, and content types. `SaveFileOptions` contains suggested name and filter. Capability queries are `CanOpenFiles` and `CanSaveFiles`; operations are `OpenFileAsync`, `OpenFilesAsync`, and `SaveFileAsync`.

## `FileSystem`

`AppDirectories` contains optional executable directory plus required data, cache, and temporary directories. `FileSystem::Directories()` returns them; `CurrentDirectory()` resolves process working directory. Obtain `FileSystem` and `FilePicker` with `UseService<T>()`.

## Complete picker example

```cpp compile="file-picker"
#include <huxerui/huxerui.h>

using namespace huxerui;

Task<void> OpenText(std::shared_ptr<FilePicker> picker, State<std::string> content) {
  auto selected = co_await picker->OpenFileAsync({
      .name = "Text",
      .extensions = {"txt"},
      .content_types = {"text/plain"},
  });
  if (!selected) {
    co_return;
  }
  auto text = co_await selected->ReadStringAsync();
  if (text.Succeeded()) {
    content = std::move(text).Value();
  }
}

[[huxerui::composable]]
View OpenTextButton(State<std::string> content) {
  auto picker = UseService<FilePicker>();
  auto tasks = UseTaskScope();
  return Button("Open text file").OnClick([picker, tasks, content] {
    tasks.Launch(OpenText(picker, content));
  });
}
```

Resolve services and task scope during composition before capturing them in an event.
Picker cancellation is represented by an empty optional. A returned `FileReference` preserves provider authority without inventing a local path.

## Directories and access-bearing paths

`FilePicker::CanOpenDirectories(writable = false)` checks the requested kind of directory access; `OpenDirectoryAsync(writable = false)` returns an optional `FileReference`. User cancellation is empty, not a directory with an empty path.

`FileReference::Type()` describes the captured entry kind. For a directory, `ListChildrenAsync()`, `CreateDirectoryAsync(name)`, and `CopyFileFromAsync(source, name, overwrite = false)` operate through its retained provider grant. `CopyDirectoryContentsToAsync(destination, overwrite = false)` accepts a File or FileReference destination and returns `FileResult<DirectoryCopySummary>`. This is not a transaction: failure/cancellation can leave already copied output; success counts are meaningful only after successful completion.

`AsFile()` returns an optional local File when the provider has a known path. It neither imports data nor transfers the reference's grant. Keep the FileReference alive while using a path that depends on its access/temporary-file ownership. Android document URIs and browser handles do not become local paths. `File::ToUri()` converts a local path to a URI; it does not manufacture provider authority.

Treat display names, captured MIME metadata, and sizes as potentially stale/untrusted. A writable directory grant does not promise every existing child can be overwritten.

## External file drops

Declared by `<huxerui/file_drop.h>`. `FileDropTarget::Accepts(FileDropOptions[, predicate])` receives ordinary files from the host drag system with Copy effect only.

```cpp compile="external-file-drop"
#include <huxerui/huxerui.h>

#include <string>
#include <vector>

using namespace huxerui;

View FileDropArea(State<std::string> status) {
  return Text("Drop text files here")
      .With(Padding(24.0F), FileDropTarget::Accepts({.extensions = {"txt"}}))
      .On<FileDropEvents::Dropped>([status](const std::vector<FileReference>& files, const FileDropEvent&) {
        status = "Received " + std::to_string(files.size()) + " files";
      })
      .On<FileDropEvents::Failed>([status](const FileError& error, const FileDropEvent&) {
        status = error.message;
      });
}
```

`extensions` and `content_types` are alternative filters; every file must pass before delivery. `allows_multiple = false` rejects a multiple-file batch in full. Metadata predicates must be quick and side-effect-free; unknown hover metadata is not proof of final acceptance.

`Entered/Moved/Exited` report hover; Exited also occurs at physical drop and does not imply cancellation. Deferred `Dropped` delivers a complete batch after validation; `Failed` reports preparation failure without partial delivery. Handlers run on the UI thread and do not run after unmount. Copy FileReference values if retaining them beyond a handler.

A drop does not read/import the content or grant write permission. Always provide an equivalent FilePicker button for touch, keyboard, accessibility, and unsupported hosts. Use [DragSource/DropTarget](/docs/reference/gesture/) for typed in-process transfers.
