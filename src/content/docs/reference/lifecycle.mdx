## `Lifecycle(setup, dependencies...)`

Registers setup in the current scope. Setup may return `void` or a callable cleanup returning `void`. Dependencies may be equality-comparable copyable values, `State<T>`, or `StateList<T>`; setup reruns when a captured value/version changes.

The previous cleanup runs before replacement.
Final cleanup runs when the declaring scope unmounts.
Without dependencies, the registration follows that scope's mount lifetime.

Call `Lifecycle` from composition rather than constructing its template machinery directly.
